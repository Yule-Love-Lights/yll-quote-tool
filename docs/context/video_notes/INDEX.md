# Video notes index

Videos mined via the `video` skill (`.claude/skills/video/SKILL.md`). One note per
video here, named `YYYY-MM-DD-<slug>.md`.

**Read this before mining a video.** Two things to check: whether this exact video
was already done, and whether a *previous* video's idea of the same shape already
has a standing reject reason. Re-mine only for a genuinely new angle, and say so.

**These notes are read on demand, not bulk-loaded.** They are not continuity docs —
do not copy them into session memory wholesale or the context cost grows with every
video. Only this INDEX is meant to be skimmed routinely.

A reject reason usually names a condition ("no crew", "not enough volume to test").
When that condition changes, the reject is worth reopening — that is why the reason
is recorded here and not just in the note.
