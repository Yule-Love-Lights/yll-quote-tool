- **AI tracing reclassification (`src/lib/photoAnalysis.ts` SYSTEM_PROMPT).** Rewrote the roofline rules so the model classifies by which way each roof plane faces: 🔴 **Santa's (red) = the FRONT roofline only** — front-facing gutters/eaves + the rakes of a FRONT-facing gable; 🔵 **Gingerbread (blue) = the ridge + the SIDE runs** (side-facing gutters/eaves + side-gable rakes). **Confirmed terms with Jason:** a *gable* = the triangular wall under a pitched peak; a *rake* = its two diagonal edges. **FRONT-SECTION-ONLY rule (added after Jason's annotated test shots):** we measure ONLY the front section of the roof facing the road — NOT the full perimeter, and NEVER the back/backyard edge (~90% of jobs; rare whole-roof/backyard jobs are done manually). The satellite rule was the big fix — it had been tracing the whole perimeter AND mis-picking the front (it traced the edge facing a neighbor's driveway, not the road); now it must correlate with street view to find the REAL road and trace only the front section. **Downspout exclusion** added: never trace the vertical gutter pipes running DOWN a wall to the ground — only the horizontal roofline.
- **Builder + training labels (`quote/new`, `training/new`):** red → **"Front Gutterline"**, blue → **"Ridge + Sides"** (buttons "+ Add Front Gutterline" / "+ Add Ridge / Side", readouts "front … · ridge+sides …").
